Marathi Marigold Cinematic Slider V5

2. Auto 8-second slides, swipe left/right or use buttons. Pause button on top.

5. Background image is included locally in assets/background.png.
6. Marathi webfonts load when online; Nirmala UI / Mangal fallback is provided offline.
