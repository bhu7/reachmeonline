Royal Marathi Scroll Wedding Invitation
1. Open index.html in Chrome (mobile portrait recommended).
2. Tap 'निमंत्रण उघडा' to reveal the parchment scroll.
3. Edit DATA near bottom of index.html to update names, functions, date, venue, WhatsApp number and Maps link.
4. Place wedding.mp3 in assets/music/ to enable music.
5. Marathi fonts load from Google Fonts online, with local fallback when offline.
6. The supplied reference poster is used as the closed cover; the opened card is live HTML, not an image with baked-in text.
