ENCHANTED GARDEN WEDDING - CINEMATIC V5

Open index.html in Chrome, Edge or a mobile browser.

All layout, CSS and JavaScript are inside index.html.
All floral art, ornaments and placeholders are local SVG assets.

CUSTOMIZE:
1. Edit names, dates, venues and ceremony text inside index.html.
2. Edit CONFIG near the bottom of index.html: weddingDate, rsvpPhone (country code, no +), rsvpMessage, mapUrl.
3. Replace assets/images/couple-1.svg, couple-2.svg and couple-3.svg with your actual photos. If using JPG/PNG, update the image src attributes in index.html.
4. Add your licensed music file as assets/music/wedding.mp3. Music starts only after clicking Open, subject to browser autoplay rules.
5. For WhatsApp previews, add a public absolute og:image URL and canonical og:url when publishing.

This is a standalone demo, ready for later Laravel dynamic-data integration.
