EMERALD BUDDHA WEDDING V5
1. Open index.html in Chrome (no server needed).
2. Click 'निमंत्रण उघडा' to start the wedding invitation.
3. Swipe left/right or use the arrow buttons to turn pages.
4. Auto Play button starts a 7-second slideshow.
5. In index.html, edit the DATA object near the bottom to change names, date, venue, Google Maps URL and WhatsApp number.
6. Add your own licensed MP3 at assets/music/wedding.mp3 for background music.
7. Background image is the original image supplied in chat.
8. Google Fonts need internet; system Devanagari fonts are used offline.
