Marathi Floral Cinematic Wedding V4
1. Open index.html in Chrome (mobile or desktop).
2. Click 'निमंत्रण उघडा'. Swipe left/right to change slides.
3. Optional background music: put your own MP3 at assets/music/wedding.mp3.
4. Edit names, dates, venue, WhatsApp link in index.html.
5. Change WEDDING_DATE in JavaScript for the countdown.
6. Marathi fonts: Google Fonts when online; Nirmala UI fallback offline.
7. Backgrounds are variations of the reference image provided by the user.
